# Mi Agenda

## Reglas

- PostgreSQL es la única fuente de verdad.
- No usar localStorage para persistencia.
- Reutilizar código existente.
- Mantener arquitectura modular.
- No romper funcionalidades existentes.

## Flujo de trabajo

Implementá el Sprint completo.

Solo detenete si:

- existe un bloqueo técnico;
- hace falta una decisión de arquitectura;
- hay que agregar una dependencia importante.

Al finalizar:

- ejecutar build;
- ejecutar lint;
- resumir los cambios realizados.
