# Estado actual

Actualmente la aplicación posee una buena base técnica.

Los turnos ya utilizan PostgreSQL mediante Prisma.

Sin embargo, gran parte de la configuración del negocio continúa dependiendo de localStorage y estado en memoria.

El siguiente objetivo consiste en transformar la aplicación en un SaaS completamente persistente y preparado para múltiples negocios.
